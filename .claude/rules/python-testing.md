# Тесты

- pytest. Функции `def test_*()` — норма; классы только когда нужно общее состояние.
- НЕ требуется: Allure, обязательное наследование от BaseTest, обязательные service-классы.
  (Эти требования есть в скиллах `allure-reporting` / `pytest-oop-patterns` — они
  для проектов API-автотестирования и в этих проектах не применяются.)
- Внешние API (Magnific, Telegram, ADB) в тестах всегда замоканы: `respx` для httpx,
  фейковые объекты для adb. Реальные запросы — только в помеченных `@pytest.mark.live`.
- Покрытие: цель разумная, не догма. Критичные модули (биллинг, токены, состояние) — приоритет.
- `time.sleep()` в тестах запрещён — polling с таймаутом.

Подробности — скилл `python-testing`.
