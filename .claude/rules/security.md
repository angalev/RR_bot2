# Секреты и безопасность

- Ни одного секрета в коде. Только `os.environ[...]` + `.env` (в `.gitignore`).
- `.env.example` с пустыми значениями — коммитится, `.env` — никогда.
- Ключи и токены не попадают в логи: при логировании запросов маскировать заголовки.
- Пользовательский ввод (промпты, команды бота) не подставляется в shell/SQL напрямую.
- Перед коммитом Stop-хук `py_guard` проверяет утечки; его предупреждения не игнорировать.
