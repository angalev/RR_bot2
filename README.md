# RR_Bot — автоматизация Rush Royale через ADB + OpenCV

Desktop-бот (Tkinter) для мобильной игры **Rush Royale** в эмуляторе
**BlueStacks**: управление идёт через ADB (тапы/свайпы по скриншотам),
распознавание поля — через OpenCV (template matching + contour matching).
Никакого чтения памяти процесса или accessibility API.

## ✅ Требования

- **Python 3.9–3.12.** Зависимости в `requirements.txt` закреплены на
  конкретные версии (`numpy==1.26.0`, `opencv-python==4.9.0.80` и т.д.) ради
  воспроизводимости, а не ради свежести — на Python 3.13 они не ставятся
  (`numpy==1.26.0` не собран под 3.13). Проверено на 3.12.
- **Windows** — `pathlib`/ADB-обёртка писались под Windows; на других ОС не
  проверялось.
- **BlueStacks** с включённым ADB-дебагом, разрешение экрана зафиксировано на
  **900×1600** — иначе все координаты тапов и шаблоны распознавания будут не
  те.
- Запуск:
  ```
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  python main.py
  ```
  Без BlueStacks окно откроется и даст выбрать юнитов, но кнопка «Старт» не
  сможет найти игру — это ожидаемо, не баг.

## 🛑 Предупреждение

Использование ботов может нарушать условия игры.  
**Используйте на свой риск. Автор не несёт ответственности за блокировку аккаунта.**

Проект опубликован в учебных/демонстрационных целях (портфолио). `tools/platform-tools/` (ADB от Google) не включён в репозиторий — `utils/adb_installer.py` скачает его автоматически при первом запуске, либо поставьте Android platform-tools самостоятельно.
